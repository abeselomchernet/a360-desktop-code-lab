# Public code lab scope

This public branch demonstrates generic, isolated Python security utilities and tests using synthetic identifiers and temporary filesystem paths. It is **not** the full A360 application, production backend, an institutionally authorized system, or a verified financial product. No personal or institutional programme data is intentionally included.

**Do not commit:** PSS source documents, manuals, workbook or governance datasets, evidence vaults, private local-state directories, cloud credentials, authentication tokens, or user/customer information. Keep real A360 integration in the existing separate local workspace until reviewed and approved for a private destination.

This CI workflow proves only that the public synthetic regression tests execute; it does not validate the complete application, business evidence, financial model parity, or Windows desktop installer.
